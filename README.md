# Student Grade Calculator 🐍

A simple Python program that calculates a student's weighted average and determines their academic result.

## 📌 Features

- Calculates a weighted average using subject coefficients
- Validates grades between 0 and 20
- Handles invalid inputs
- Displays the final average
- Gives a mention based on the result

## 🛠️ Technologies

- Python
